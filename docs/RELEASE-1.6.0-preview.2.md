# Filebridge-Lan 1.6.0 Preview 2

发布日期：2026-11-13

这是一个 **Preview**，不是稳定版。它包含新的文字同步和一轮界面整理，但仍有明确列出的 UI 缺陷，且尚未完成真实手机、真实桌面窗口和跨网络环境的完整验收。

## 新功能

### 文字同步

- 在已批准并持有有效 token 的连接内双向同步纯文本。
- 桌面系统剪贴板中的新文本会同步到已连接手机网页；手机发送的文本会写入电脑系统剪贴板。
- 手机端提供最新文本、更新时间、复制、从剪贴板读取、手动输入/发送和清空。
- 默认开启，可随时关闭；只有主机 loopback 可以切换。
- 单条文本上限 256 KiB，只接受 text/plain。
- 内容仅保存在 Hub 内存，不写入磁盘；不进入发现广播、URL、普通日志或上传诊断。
- Node Hub 与 Rust Hub 使用相同协议、错误码和大小限制；按哈希去重，避免同步回声。
- 浏览器剪贴板权限受限时，文本仍保留，可手动复制和输入。

### 工作台与交互

- 桌面主界面改为文件列表/传输进度为主行，连接/附近电脑为支持行，文字同步为下方全宽次要区域。
- 900px 非全屏窗口改为顶部横向导航，并保持双列，不再退化为单卡片一行。
- 文件列表按内容高度自适应，设置最大高度内部滚动；连接卡不再被强行拉伸。
- 使用说明对话框增加入场/退场动效，支持 reduced-motion。
- 使用说明现在真正限制键盘焦点，背景 `inert`，关闭后焦点回到触发按钮。
- 空闲态保留速率卡，但降低零值和空图表的视觉重量。

## 已知 UI 缺陷

这些是已知问题，不阻塞 Preview 验收，但不应被描述为已完成：

- **使用说明仍是区域图例**，没有覆盖文字同步和附近电脑；“配对码 / 访问码 / code”三种说法仍不统一。
- **顶部模式切换仍把实验性的“跨网络中继”与“局域网直传”放在同等视觉权重**，手机首屏也会出现实验入口。
- **文字同步面板仍有 5 个同级动作**（复制、从剪贴板读取、清空、关闭同步、发送），默认开启的说明不够显眼。
- **手机端拖放提示**仍写着“支持多选 / 拖放”，但触屏无法拖放；手机文件名和 SHA 前缀会截断。
- **文件选择复选框只有 14px**，小于 44px 触控目标；触屏上需要精确点按。
- **900px 横向导航**是本版新增行为，尚未在真实 Windows 的 900×600 窗口和触屏笔记本上验收。
- **桌面附近电脑右列**（连接卡右侧）尚未在真实局域网发现状态下截图确认。
- 设置页在浏览器模式下只有说明文字，没有可操作设置；这是既有设计，未在本版重构。
- 测试/诊断面板、跨网络 Relay、Public 网络门禁的外观保持既有状态。

## 尚未完全测试的功能

- **iPhone Safari / Android 真实设备**：复制权限、从剪贴板读取权限、前后台切换、手动回退路径。
- **桌面自动系统剪贴板同步端到端**：系统剪贴板读写命令已单独 roundtrip 测试，但“开启后自动轮询 → 手机收到 → 手机发送 → 系统剪贴板写入”的完整 UI 链路尚未在真实可见桌面窗口验收。
- **断线、Public 暂停、恢复**后的文字缓存清理和恢复。
- **Windows 10**、不同 DPI/缩放、触屏笔记本、900×600 默认窗口下的视觉与焦点顺序。
- **真实双机附近发现**下，连接卡与附近电脑同排的桌面布局。
- **跨网络中继**的真实 WAN 环境；它仍是实验性功能。
- 安装包未签名，Windows SmartScreen 可能提示；没有代码签名验证。
- 多文件大文件、Safari 分块续传和现有文件传输回归只由自动化测试覆盖，未在本 Preview 中重新做完整真机回归。

## 安装

下载 `Filebridge-Lan_1.6.0-preview.2_x64-setup.exe` 并按提示安装。安装器需要 UAC 配置专用网络防火墙规则；不会修改 Public 网络规则。

# Filebridge-Lan 架构文档

> ⚠️ 本文是早期目标架构，不是 2026-10-23 的实际实现。现状见 [AUDIT.md](./AUDIT.md)，HTTP Hub API 见 [HTTP-HUB.md](./HTTP-HUB.md)。

## 概述

跨平台文件传输工具。桌面端（Tauri）+ 移动端（PWA）。局域网优先，WebRTC P2P。

## 技术栈

```
层            | 技术
---------------|--------------------------
桌面壳         | Tauri（Rust）
移动端         | PWA（Service Worker）
前端           | React + Vite + TypeScript
P2P传输        | WebRTC DataChannel
信令           | WebSocket（本地服务器）
发现           | mDNS + UDP广播 + WS中继
加密           | Web Crypto API（ECDH + AES-256-GCM）
```

## 数据流

### 配对流程
```
桌面端                     移动端
   │                         │
   ├─ 生成PIN ───────────────┤
   │  显示二维码              │
   │                         ├─ 扫描/输入PIN
   │                         ├─ 生成ECDH密钥对
   ├─ 验证PIN ───────────────┤
   │  生成ECDH密钥对          │
   ├─ 交换公钥 ──────────────┤
   │                         │
   ├─ 派生共享密钥 ──────────┤
   │  (ECDH)                 │
   ├─ 派生AES密钥 ──────────┤
   │                         │
   └─ 存储信任 ──────────────┘
```

### 文件传输流程
```
发送方                     接收方
  │                          │
  ├─ 选择文件 ───────────────┤
  ├─ 计算SHA-256 ───────────┤
  ├─ 确定传输模式 ──────────┤
  │  (<16MB = 直接)          │
  │  (>=16MB = 分块)         │
  ├─ 发送传输请求 ──────────┤
  │                          ├─ 接受/拒绝
  ├─ 接收响应 ──────────────┤
  │                          │
  ├─ [分块模式] ────────────┤
  │  分割为分块              │
  │  遍历每个分块：           │
  │   ├─ 读取分块 ──────────┤
  │   ├─ 计算哈希 ──────────┤
  │   ├─ 通过DC发送 ────────┤
  │   │                      ├─ 验证哈希
  │   ├─ 等待确认 ──────────┤
  │   │                      ├─ 发送确认
  │   └─ 失败重试 ──────────┤
  │                          │
  ├─ 发送完成 ──────────────┤
  │                          ├─ 验证文件哈希
  │                          ├─ 保存文件
  └─ 完成 ──────────────────┘
```

## 协议规范

### 发现协议
- 传输层：UDP多播 (224.0.0.251:42069) + WebSocket中继
- 格式：JSON
- 间隔：每5秒广播，15秒超时
- 消息类型：announce, query, response, bye

### 传输协议
- 控制：JSON over WebSocket
- 数据：二进制 over WebRTC DataChannel
- 分块大小：默认256KB，自适应最大1MB
- 完整性：每分块+全文件SHA-256
- 重试：每分块最多3次
- 超时：每分块30秒

### 安全协议
- 配对：6位PIN（2分钟过期）
- 密钥交换：ECDH P-256
- 会话密钥：AES-256-GCM
- 信任存储：localStorage（待加密存储）

## 平台说明

### 桌面端（Tauri）
- 原始UDP套接字用于mDNS/广播
- 通过Tauri API访问文件系统
- 系统托盘支持后台运行
- 本地WebSocket信令服务器

### 移动端（PWA）
- WebSocket连接桌面端信令
- WebRTC用于P2P数据传输
- File System Access API保存文件
- Service Worker支持离线能力

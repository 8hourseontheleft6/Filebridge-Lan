# Filebridge-Lan 1.4.2

发布日期：2026-10-30

1.4.2 是界面和文件管理版本，保留 1.4.0/1.4.1 的配对 token、安全收紧、拖放和打开目录修复。

## 界面

- 改为 FlClash 风格的浅色卡片仪表盘：左侧导航、顶部状态、文件列表、扫码连接、传输进度分区
- 文件列表支持多选、全选和批量保存/下载
- 新增批量删除：一次确认后删除所选文件
- 文件列表限制最大高度并增加可拖动滚动条，文件多时页面不会被无限拉长
- 上传/下载速率卡片：当前速度、峰值、累计传输量和实时曲线
- 设置页新增版本信息、传输原理、存储位置和安全说明
- 局域网二维码链接支持一键显示/隐藏 code

## 传输与存储

- 局域网仍是 HTTP 直传；配对码/ token 只做访问控制，不是内容加密
- 上传文件保存在电脑的 `Downloads/Filebridge-Lan`，点击保存后复制到下载目录
- 跨网络中继为实验性 AES-256-GCM 端到端加密，未完成真实 WAN 验证

## 安装

安装包由 GitHub Actions 在 tag `v1.4.2` 上构建并上传，SHA-256 见 Release 资产 digest 和发布正文。

- 安装结束如出现 UAC，请允许一次（TCP 42080 防火墙规则）
- 安装包未签名，未构建 MSI

## 已知限制

- 局域网 HTTP 明文；敏感文件应使用可信网络或等待局域网端到端加密版本
- 手机浏览器批量下载由浏览器管理，应用内下载速率卡片只跟踪桌面原生保存
- 跨网络中继仍未完成真实手机蜂窝网络 + 电脑另一网络的 WAN 验证，不应作为生产级公网服务
- 未实现上传断点续传；大文件接收端在内存组装 Blob

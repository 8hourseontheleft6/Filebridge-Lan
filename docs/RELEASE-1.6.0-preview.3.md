# Filebridge-Lan 1.6.0 Preview 3

发布日期：2026-11-14

这是一个 **Preview**，不是稳定版。它把桌面传输界面整体重做了一遍，并把防火墙配置内置进安装包；但真实手机、真实双机与跨网络环境仍未按本构建完整验收。

## 界面与交互

### 传输速率卡

- 上传与下载拆成两张独立卡片，与文件列表同高（≥900px 时固定 300px），不再随内容跳动。
- 每张卡只保留当前速率读数、峰值、累计和底部速率折线；批量上传只显示「第 X/Y 个」，不再叠加进度条或重复百分比。
- 传输结束后卡片回到空闲态。

### 文件列表

- 固定高度，行不再被挤压；空列表时提示写在列表内：「把文件拖到窗口任意位置，或点右上角 + 上传」。
- 列表头部动作全部改为圆形图标：全选、选择文件、打开下载文件夹、刷新文件列表；批量保存/删除仍为文字按钮。
- 删除文件与删除进度块使用退场动画收起（约 340ms），不再瞬间消失。

### 拖放

- 文件可拖到窗口任意位置：薄纱淡入 → 虚线框收拢 → 目标卡上浮 → 加号弹出；拖离/放下时用更快的释放动画。
- `prefers-reduced-motion` 下关闭动画，但静态提示仍然可见。

### 上传进度

- 进度块只保留「总进度 · 第 X/Y 个」、已传/总量与剩余时间；取消按钮为圆形 ✕。
- 取消后可点同一位置的圆形刷新按钮重新上传，不再显示「已取消，可继续上传」的说明文字。
- 上传完成后保留约 1.6 秒显示「已上传」，随后收拢消失。

### 配对与二维码

- 配对详情默认折叠，展开后才显示配对码；复制与刷新配对码改为圆形图标。
- 提示压缩为一句「扫码即可连接；配对码仅用于授权。」

### 使用说明

- 从「区域图例」改为 6 步上手流程：连同一局域网 → 手机扫码 → 选文件 → 保存 → 看进度与取消重试 → 可选电脑互传与文字同步。
- 保留专用网络限制与「局域网是 HTTP 明文」的边界提示。

## 安装器

- Windows 防火墙规则内置进安装包，不再额外启动可见的 PowerShell 窗口：
  - 常规路径（规则已存在且指向当前 exe）用 `netsh` + `findstr` 原生探测，不弹窗、不提权、不启动 PowerShell；
  - 规则缺失或过期时才请求一次管理员授权，并以隐藏窗口运行内置脚本（`-WindowStyle Hidden` + `SW_HIDE`）；
  - 脚本只在安装期间解压到临时目录，安装结束即删除；不再往安装目录写 `install-firewall.ps1`，并清理旧版本遗留文件；
  - 仍只放行 TCP 42080 / UDP 42081，Domain/Private，不修改 Public 规则。
- `npm run test:version` 现在同时校验界面上的版本标签，避免版本号与界面不一致。

## 已知问题

以下问题仍然存在，不应被当作已完成：

- 顶部模式切换仍把实验性的「跨网络中继」与「局域网直传」放在同等视觉权重，手机首屏也会出现实验入口。
- 文字同步面板仍有多个同级动作（复制、从剪贴板读取、清空、关闭同步、发送），默认开启的说明不够显眼。
- 触控目标尺寸（行内复选框、圆形图标按钮）未按 44px 触控标准验收。
- 900px 附近的横向导航、真实 Windows 900×600 窗口、触屏笔记本的布局与焦点顺序尚未验收。
- 设置页在浏览器模式下只有说明文字，没有可操作设置。
- 安装包未签名，Windows SmartScreen 可能提示。

## 安装

下载 `Filebridge-Lan_1.6.0-preview.3_x64-setup.exe` 并按提示安装。

首次安装（或防火墙规则失效时）需要一次 UAC 授权来配置专用网络防火墙；规则已指向安装目录的 exe 时，重装/升级完全静默，不会出现 PowerShell 窗口。

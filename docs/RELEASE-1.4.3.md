# Filebridge-Lan 1.4.3

发布日期：2026-10-30

1.4.3 是 1.4.2 的布局补丁版本，不改变传输协议、数据目录和安全边界。

## 布局调整

- “扫码连接”卡片移到“文件列表”上方
- 扫码连接、文件列表、传输进度三个主卡片统一同宽并垂直排列
- 桌面与手机保持相同的阅读顺序：先连接，再选文件，再看进度
- 文件列表仍保留多选、批量保存/下载、批量删除和滚动条

## 保留的 1.4.2 内容

- 浅色卡片仪表盘、上传/下载速率卡片
- 文件列表批量操作
- 设置页版本信息与说明
- 配对 token、二维码显示/隐藏 code、拖放和打开目录修复

## 安装

安装包由 GitHub Actions 在 tag `v1.4.3` 上构建并上传，SHA-256 见 Release 资产 digest 和发布正文。

- 安装结束如出现 UAC，请允许一次（TCP 42080 防火墙规则）
- 安装包未签名，未构建 MSI

## 已知限制

- 局域网直传仍是 HTTP 明文，只有访问码保护
- 跨网络中继仍是实验性功能，未完成真实 WAN 验证

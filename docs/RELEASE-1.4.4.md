# Filebridge-Lan 1.4.4

发布日期：2026-10-30

1.4.4 是 1.4.3 的桌面布局修复版，不改变传输协议、数据目录和安全边界。

## 修复

- 修复 861–1050px 窗口下三张卡片只占左半边、右侧留白的问题
- 删除 `@media (max-width: 1050px)` 中残留的旧双列 `grid-template-columns`
- 扫码连接、文件列表、传输进度在桌面窗口下统一占满内容宽度
- 上传/下载速率卡片在正常桌面宽度下恢复并排显示，仅在窄屏手机上下堆叠

## 保留的 1.4.3 内容

- 扫码连接在上、文件列表在下
- 三张主卡片同宽
- 批量保存/下载/删除、列表限高滚动条
- 浅色仪表盘、设置页版本说明
- 配对 token、二维码显示/隐藏 code、拖放和打开目录修复

## 安装

安装包由 GitHub Actions 在 tag `v1.4.4` 上构建并上传，SHA-256 见 Release 资产 digest 和发布正文。

- 安装结束如出现 UAC，请允许一次（TCP 42080 防火墙规则）
- 安装包未签名，未构建 MSI

## 已知限制

- 局域网直传仍是 HTTP 明文，只有访问码保护
- 跨网络中继仍是实验性功能，未完成真实 WAN 验证

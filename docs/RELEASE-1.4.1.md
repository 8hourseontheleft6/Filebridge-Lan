# Filebridge-Lan 1.4.1

发布日期：2026-10-25

1.4.1 是 1.4.0 的小版本更新，保留 1.4.0 的 HTTP 配对 token、安全收紧和桌面修复。

## UI

- 局域网二维码区域增加“显示 code / 隐藏 code”按钮
- 默认仍隐藏链接末尾的 6 位配对码；点击后可直接在页面上查看完整链接末尾的 code
- 方便另一台电脑不复制链接、直接读取 code 后手动连接
- 复制链接按钮始终复制完整链接，不受显示状态影响

## 保留的 1.4.0 内容

- 6 位配对码只用于配对；配对后 256-bit token，12 小时过期
- Host/Origin 白名单，CORS 不使用 `*`
- 防火墙仅 TCP 42080、Private/Domain
- 移除 WebRTC、42070 和房间概念
- 跨网络中继使用 accessToken/downloadToken、HTTPS/可信代理、原子配额和 SHA-256 校验

## 安装

安装包由 GitHub Actions 在 tag `v1.4.1` 上构建并上传，SHA-256 见 Release 资产 digest 和发布正文。

- 安装结束如出现 UAC，请允许一次（TCP 42080 防火墙规则）
- 安装包未签名，未构建 MSI

## 已知限制

- 局域网 HTTP 明文；token 不是加密
- 未实现上传断点续传
- 跨网络中继仍是实验性功能，未完成真实手机蜂窝网络 + 电脑另一网络的 WAN 验证，不应作为生产级公网服务
- 跨网络接收端在内存组装 Blob，超大文件受手机内存限制
